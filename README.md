# Reigns landing page

Marketing site for [Reigns](https://github.com/arnovkandlikar/reigns), the macOS companion that watches your Claude chats and catches hallucinations.

Built with Vite + React. The hero uses the [RefineFrame](https://reactbits.dev) component from React Bits.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

Mamu and Mia are generated from the companion app's drawing code:

```bash
python3 scripts/make_characters.py
```
